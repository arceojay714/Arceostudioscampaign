# Block: the ask

One ask. Never a menu. A proposal that offers three options gets a reply about which option,
which is a reply about us, which is not a decision.

Tier A, first touch:
> I'm at the club often enough that this is easy — could I photograph your management team
> one morning in the next few weeks?

Tier B/C, first touch:
> Would it be worth fifteen minutes to talk about how this would run at [CLUB]?

Second touch:
> If the timing is wrong this year, would it help if I sent this again in the spring?

Third and final touch:
> I'll leave it here. If a portrait week ever gets onto the calendar, I'd like to be the
> call you make.

The third touch is not a pitch. It's a clean exit that leaves the door open, and it gets a
surprising number of replies precisely because it asks for nothing.
