# Proposal blocks

Reusable sections. A proposal is assembled from these plus a signal-specific opening, so
quality stops varying with how tired Jay was the night he wrote it.

Rules: one page assembled, always. Never use more than four blocks in one letter. The
opening paragraph is always written fresh for that club — if it could be sent to any club,
it isn't ready.

| Block | Use when |
|---|---|
| `01-directory-argument` | Default core. Almost every proposal. |
| `02-costs-the-club-nothing` | Always. This is what gets a board to yes. |
| `03-free-management-shoot` | Tier A only — anywhere Jay can drive. The strongest opener we have. |
| `04-on-site-logistics` | When the reply is warm and they're picturing the day. |
| `05-family-sitting` | Family-heavy clubs, summer, or clubs with junior programs. |
| `06-heritage` | Anniversary or milestone-year clubs. |
| `07-terms-and-insurance` | Second touch onward, or any club with a purchasing process. |
| `08-the-ask` | Always. One ask, never a menu. |
