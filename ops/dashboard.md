# Weekly dashboard

One page, Mondays, generated by the weekly task. Trends are invisible without it, and every
number here is already sitting in `ops/sessions.csv` or `outreach/log.csv`.

## Template

**Week of [DATE]**

*Outreach*
- New prospects added / total in list
- Touches sent (by tier), replies received, reply rate
- Clubs at `signal-waiting`, clubs at `replied`
- Free management shoots: offered / booked / completed
- Clubs won this week

*Sessions*
- Booked / shot / delivered
- Average order value, revenue
- Sessions stuck in the pipeline for more than 7 days

*Campaign*
- Ad spend vs $18/day plan, landing page views, cost per view
- Audience sizes for the three retargeting tiers, and whether they grew

*Content*
- LinkedIn posts published, reviews received, testimonials collected

*One line: what changed this week that I would not have noticed.*

## Rules

- Report the trend, not just the number. A single week's figure means nothing.
- If a number can't be sourced from a file in this repo, don't invent it — say it's
  unavailable and note what would need to be tracked to get it.
- Flag the absence of movement. Four weeks of flat retargeting audiences is a finding.
