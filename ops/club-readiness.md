# Club readiness checklist

Clubs are institutional buyers. The gap between a warm yes and a signed date is almost
never about photography — it's about paperwork the club needs before it can let a vendor
on site. Every one of these is cheap to prepare in advance and expensive to scramble for
after a GM says yes.

| Item | Status | Notes |
|---|---|---|
| Certificate of insurance (general liability) | **not staged** | Must be able to name the club as additional insured. Ask the broker what the turnaround is — that number is our real response time. |
| W-9 | **not staged** | Trivial, blocks payment if missing. |
| Services agreement template | **not staged** | Scope, dates, cancellation, image rights, payment terms. One page. |
| Member consent / model release | **not staged** | Must include a directory-only option. Members who don't want to be in marketing still want to be in the directory. |
| Business license, per jurisdiction | **check** | WA and CA both in play; Tier B travel adds more. |
| Sample directory spread | **not staged** | A physical example of finished work matters more than any document here. |
| Reference list | **thin** | The free management shoots are how this gets built. First three become the reference list. |

**Being able to answer all of these inside one business day is a genuine competitive
advantage** over a solo photographer who cannot, and it is entirely within our control.

Update this file as items get staged. It gets reviewed the first time any club replies warm.
